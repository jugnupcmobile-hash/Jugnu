# BT Chat - Offline Bluetooth Chatting App

## Build APK Automatically (No Android Studio Needed)
1. Create a new repository on GitHub (public or private).
2. Extract this ZIP and push/upload all files (including `.github/workflows/build-apk.yml`) to the repository.
3. Open the **Actions** tab on GitHub.
4. Wait ~3–5 minutes for **Build BT Chat APK** to complete.
5. Download the **BT-Chat-APK** artifact and install `app-debug.apk` on two Android phones.
